# Fuentes · 129 · Cómo funciona el mando del garaje

| Dato del guion | Fuentes (≥2 URL completas por fila) | Estado |
|---|---|---|
| Los mandos con código rodante envían un código distinto en cada pulsación (b1, b2) | https://en.wikipedia.org/wiki/Rolling_code ; https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf (hoja de datos de un codificador de código rodante: «This data will change with every button press») | Verificado |
| El código rodante existe para impedir que alguien grabe la señal y la repita (ataque de repetición / «code grabber») (b2) | https://en.wikipedia.org/wiki/Garage_door_opener ; https://en.wikipedia.org/wiki/Rolling_code ; https://courses.ece.ubc.ca/412/term_project/reports/2009/Security%20Analysis%20of%20Electric%20Garage%20Doors.pdf | Verificado |
| Mando y receptor comparten un secreto (clave/semilla) que no se transmite en la pulsación normal; el receptor lo guarda al «aprender» el mando (b3) | https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf (clave de cifrado de 64 bits; «Learning involves the receiver calculating… the crypt key») ; https://en.wikipedia.org/wiki/Rolling_code (semilla compartida previamente, como en HOTP) | Verificado (simplificado: «el secreto no se envía al pulsar»; en algunos modos de aprendizaje seguro se envía una semilla, nunca en el uso normal) |
| En Europa los mandos usan bandas de radio libres como la de 433 MHz (o 868 MHz) (b4) | https://en.wikipedia.org/wiki/LPD433 («garage or gate openers») ; https://en.wikipedia.org/wiki/Short-range_device (433,050–434,790 MHz y 863–870 MHz, «remote garage door openers») ; https://en.wikipedia.org/wiki/Remote_keyless_system (433,92 MHz en Europa para llaves de coche) | **Aproximado**: la voz dice «por ejemplo, a cuatrocientos treinta y tres megahercios» porque conviven 433 y 868 MHz; no hay dato de cuál es mayoritaria |
| Los mandos antiguos enviaban siempre el mismo código, fijado con 8 a 12 interruptores (DIP) → 256 a 4096 combinaciones (b5, rótulos) | https://en.wikipedia.org/wiki/Garage_door_opener («8 to 12 DIP switches», 256–4096) ; https://courses.ece.ubc.ca/412/term_project/reports/2009/Security%20Analysis%20of%20Electric%20Garage%20Doors.pdf («8 dip switches… 256 different codes») | Verificado (combinaciones calculadas con interruptores de dos posiciones) |
| El código fijo se podía grabar y repetir; servía hasta que se cambiaran los interruptores (b6) | https://en.wikipedia.org/wiki/Rolling_code (código fijo: capturar y reutilizar) ; https://courses.ece.ubc.ca/412/term_project/reports/2009/Security%20Analysis%20of%20Electric%20Garage%20Doors.pdf (ataque de repetición en mandos DIP) | Verificado |
| El mando lleva un contador que sube uno en cada pulsación (b7) | https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf («16-bit synchronization counter… increments each time a button is pressed») ; https://en.wikipedia.org/wiki/Rolling_code (contador de 16 bits dentro de la parte cifrada) | Verificado |
| El contador se cifra con la clave secreta y sale un código que parece aleatorio (b8) | https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf («appearing externally to ‘randomly hop around’») ; https://en.wikipedia.org/wiki/Rolling_code (generador pseudoaleatorio / criptográfico) | Verificado |
| El receptor descifra, comprueba el contador y solo acepta códigos nuevos (los usados se ignoran) (b9) | https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf (flujo del decodificador y «Blocked Window») ; https://en.wikipedia.org/wiki/Rolling_code | Verificado |
| El receptor acepta una ventana de códigos por delante por si pulsaste sin que te oyera (b10) | https://en.wikipedia.org/wiki/Rolling_code («within the next 256 codes») ; https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf (ventana de 16 códigos directa y hasta 32K con doble pulsación) | **Aproximado**: el tamaño de la ventana depende del sistema (16, 256, hasta 32 768); la voz dice «unos cuantos» y en pantalla es ilustrativo (42 → 46) |
| Curiosidad: si pulsas muchísimas veces sin que el receptor te oiga, el mando se sale de la ventana y hay que volver a emparejarlo (b11) | https://www.overheaddoors.com/blog/why-did-my-garage-door-remote-stop-working/ («accidental button presses, or complete battery drainage can cause your remote transmitter to lose sync»; se re-sincroniza con el botón de aprendizaje) ; https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf (fuera de la ventana el código se ignora) ; https://en.wikipedia.org/wiki/Rolling_code | Verificado («muchísimas» porque el número depende del sistema) |
| Otra: con la pila baja la señal es más débil y el mando solo funciona de cerca (b12) | https://support.chamberlaingroup.com/s/article/ARQ-remote-only-work-when-close-to-the-garage-door-opener («A weak battery can also lead to diminished range») ; https://www.overheaddoors.com/blog/why-did-my-garage-door-remote-stop-working/ | Verificado |
| (tiktok_gancho) Hay mandos que envían en cada mensaje un aviso de pila baja | https://ww1.microchip.com/downloads/en/DeviceDoc/21143c.pdf («The VLOW bit is included in every transmission») ; https://en.wikipedia.org/wiki/Rolling_code (2 bits de estado: repetición y pila baja) | Verificado |
